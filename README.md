# sakura-typing

医療職向け漢字タイピングWebアプリ「桜うち」

## Overview

医師事務作業補助者業務における入力速度の重要性を知ったことをきっかけに開発した、医療用語対応のタイピングゲームです。

診療科ごとの専門用語・漢字を題材に、楽しみながら入力練習ができるよう設計しました。

桜の花びらが落ちるまでに入力するゲーム形式を採用し、連続成功時には速度が上がり、ミスが続くと速度が下がる適応型の難易度調整を実装しています。

## Technology

- Python
- Flask
- JavaScript
- HTML
- CSS

## Features

- 診療科別の医療用語タイピング
- 桜の花びら落下アニメーション
- 入力速度に応じた難易度調整
- Webアプリとして公開
